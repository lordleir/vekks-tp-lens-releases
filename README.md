# Vekk's TP Lens

Check Trading Post prices by hovering over an item, without searching for it manually.

## Features

- Highest buy order and lowest sell listing
- Prices for the item's upgrades and infusions
- Unit prices and estimated totals for item stacks

## Installation

Download [VekksTPLens.dll](https://github.com/lordleir/vekks-tp-lens-releases/releases/latest/download/VekksTPLens.dll), close Guild Wars 2, and place it in the game's `addons` folder. Launch the game with Nexus.

Requires Nexus and Windows x64.
