# Vekk's TP Lens

Download the latest `VekksTPLens.dll` from [Releases](https://github.com/lordleir/vekks-tp-lens-releases/releases/latest).

Close Guild Wars 2, place the DLL in the game's `addons` folder, and launch with Nexus. Requires Windows x64.

This repository contains compiled releases only; the source code is kept private.
